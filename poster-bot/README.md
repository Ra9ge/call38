# Poster Bot — постеры аниме с русским названием

Берёт постер с **Shikimori** по ID и делает из него русский постер:

1. **На постере есть название** — японское или латиницей (HUNTER×HUNTER, Steins;Gate, CODE GEASS…) →
   стирает его и на том же месте рисует русское:
   - **шрифт под аниме**: тонкий логотип с засечками («минтё») → шрифт с засечками, иначе по жанрам
     с Shikimori: романтика/повседневность → округлый, экшен/спорт → жирный плакатный,
     меха/фантастика → «техно», ужасы/жестокость/триллер → потёртый, мистика/история → с засечками;
   - **цвета из оригинала** — цвет букв, обводка, градиент; если на фоне они не читаются — белые/тёмные;
   - **размер** — по месту старого логотипа, длинное название переносится на 2–3 строки
     (в том числе по дефису: «ЧЕЛОВЕК- / БЕНЗОПИЛА»), строки с одинаковыми отступами;
   - **номер сезона просто цифрой в конце**: «Атака титанов 2», «Код Гиас: Восставший Лелуш R2» —
     без отдельной подписи «ВТОРОЙ СЕЗОН» другим шрифтом;
   - под русским названием мелко — оригинальное (английское) название;
   - **японское название столбиком** вдоль края → русское тоже пишется вдоль того же края
     (повёрнутым, как корешок книги), а не поперёк постера через лица.

   Разноцветные логотипы с табличками и лепестками (как «Кошечка из Сакурасо») копируются
   буква в букву: те же цвета слева направо, белая обводка-«стикер», табличка, наклон.
2. **Названия на постере нет** → накладывает название в стиле «ОТЕЛЬ ◆ ДЛЯ ◆ НЕЛЮДЕЙ»:
   подпись сезона сверху («ВТОРОЙ СЕЗОН»), крупный потёртый заголовок с ромбами,
   английское название снизу. Место выбирается так, чтобы не закрывать лица.

Тонкие логотипы с засечками (как у «Восхождения в тени») делаются заглавными с крупной буквицей.
Если название налезает на лого в углу, оно сдвигается.

**Как ищется название.** Весь текст на постере сравнивается со всеми названиями аниме с Shikimori
(японским, английским, ромадзи, синонимами) — так находятся и латинские логотипы, и логотипы,
разбитые на части. Крупная надпись, которую не удалось прочитать (сильно стилизованный логотип,
как у «Евангелиона»), тоже считается логотипом. Вертикальные японские названия (столбиком)
разрезаются на иероглифы и читаются заново. Титры и прочие мелкие надписи не трогаются.

**Чтобы не просвечивал старый текст:**
- стирается не только сама надпись, но и её тень/свечение вокруг букв;
- нейросеть, которая дорисовывает фон, не видит ни одного пикселя старых букв (иначе она
  «дорисовывает» из них призрак надписи); длинные логотипы обрабатываются по частям почти
  в родном размере;
- после стирания постер проверяется ещё раз — на месте логотипа и рядом с ним (кусок названия,
  который сначала не нашёлся). Если что-то читается — стирается повторно (до двух раз). Если всё
  равно осталось — в отчёте будет пометка «старый текст стёрся не полностью».

Мелкий японский текст (даты, «放送開始» и т.п.) тоже стирается.

## Быстрый старт

**Windows:** нужен **Python 3.13** (подойдут 3.11–3.14, только 64-bit): для более новых версий,
например 3.15, библиотеки нейросетей пока нет. Если стоит другой Python — не страшно:
`run.bat` сам найдёт подходящий, а если его нет — попробует поставить 3.13 сам
(если не получится — поставь вручную с [python.org/downloads/windows](https://www.python.org/downloads/windows/):
«Windows installer (64-bit)», при установке отметь «Add python.exe to PATH»; старый Python удалять не нужно).
Потом просто дважды кликни `run.bat` и введи ID или ссылку. Первый запуск сам поставит всё нужное (пара минут).

```bat
run.bat 13759
run.bat 13759 --badge "НОВАЯ ОЗВУЧКА"
run.bat https://shikimori.one/animes/z13759-sakura-sou-no-pet-na-kanojo
```

**Linux / macOS:**

```bash
./run.sh 13759 --badge "НОВАЯ ОЗВУЧКА"
```

Готовые постеры появятся в папке `output/`. Можно передать сразу несколько ID через пробел.

## Ночной режим: постеры для всех аниме

**Windows:** дважды кликни `night.bat` и иди спать. **Linux/macOS:** `./night.sh`.

Скрипт сам берёт список аниме с Shikimori (по умолчанию TV, фильмы, OVA и ONA, без 18+,
сначала самые популярные) и делает постеры подряд:

- готовые постеры — `output/batch/posters/` (JPG ~0.5 МБ; `--format png` — ~1.6 МБ);
- **отчёт** `output/batch/index.html` — все постеры плиткой, рядом маленький оригинал,
  чтобы утром быстро пролистать и найти неудачные; обновляется каждые 25 постеров;
- можно закрыть окно или нажать Ctrl+C — при следующем запуске продолжит с того же места;
- пропал интернет — ждёт и повторяет (до ~20 минут), а не падает;
- компьютер не уходит в сон, пока идёт работа; клик по окну консоли её не останавливает;
- ошибки записываются в `output/batch/batch.log` и повторяются при следующем запуске.

Сначала лучше пробный запуск на 20 штук и посмотреть отчёт:

```bat
night.bat --limit 20
```

Полезные настройки (дописываются после `night.bat` или `python batch.py`):

| Флаг | Что делает |
|---|---|
| `--hours 8` | остановиться через 8 часов |
| `--limit 1000` | сделать 1000 новых постеров |
| `--kind tv,movie` | только эти типы (`all` — все, включая спешлы и клипы) |
| `--min-score 7` | только с оценкой от 7 |
| `--season 2010_2026` | только вышедшие в эти годы |
| `--status released` | только вышедшие (`ongoing` — выходят, `anons` — анонсы) |
| `--ids-file list.txt` | свой список: ID или ссылки, по одному в строке |
| `--badge "НОВАЯ ОЗВУЧКА"` | плашка на всех постерах |
| `--redo --offline` | перерисовать всё заново из уже скачанных оригиналов, без интернета (например, после обновления скрипта) |

### Если Shikimori не отвечает

Запусти `check.bat` (Linux/macOS: `./check.sh`). Он проверит каждый адрес Shikimori и напишет,
что именно не так («адрес не найден», «не отвечает», «ответ 403» …) и что делать.

- Если https://shikimori.io не открывается и в браузере — сайт недоступен из твоей сети, нужен VPN.
- Если в браузере открывается только с VPN-**расширением** — программа его не видит. Включи VPN
  для всей системы (режим TUN или «системный прокси» в приложении VPN) или укажи прокси приложения:
  `check.bat --proxy socks5://127.0.0.1:10808` (порт — в настройках VPN), и потом так же
  `night.bat --proxy socks5://127.0.0.1:10808`.
- Свой адрес Shikimori можно задать переменной окружения `SHIKIMORI_URL`.

### Сколько это занимает

Замер на 4-ядерном процессоре без видеокарты:

- постер **с японским названием** (стирание + новое название): **6–9 секунд**;
- постер **без японского текста** (название поверх): **около 1 секунды**;
- при запуске ещё ~10 секунд на загрузку нейросети (один раз).

В среднем выходит примерно 400–700 постеров в час, то есть **3–5 тысяч за ночь** (8 часов).
На быстром процессоре — больше. Точную скорость скрипт пишет в каждой строке
(«среднее … с · ~…/ч»), с `--limit` — ещё и сколько осталось.

## Настройки

| Флаг | Что делает |
|---|---|
| `--badge "НОВАЯ ОЗВУЧКА"` | красная плашка под названием (цвет: `--badge-color "#e2343a"`) |
| `--mode replace / overlay` | принудительно заменить японское название / наложить своё |
| `--title "..."` | своё русское название вместо названия с Shikimori |
| `--label "ВТОРОЙ СЕЗОН"` | подпись над названием (`--label ""` — убрать) |
| `--subtitle "..."` | подпись под названием в режиме наложения (`""` — убрать) |
| `--font heavy / grunge / rounded / tech / serif` | стиль шрифта: жирный / потёртый / округлый / «техно» / с засечками (или `путь.ttf`) |
| `--no-fun` | без «прыгающих» букв и чередования регистра |
| `--distress 0.5` | сила потёртостей (0 — без них) |
| `--keep-other-text` | не стирать мелкий японский текст |
| `--logo assets/logo.png` | водяной знак (по умолчанию берётся `assets/logo.png`, если он есть), `--logo none` — без него |
| `--image файл.jpg` | взять свою картинку вместо постера с Shikimori |
| `--format png / jpg / webp` | формат результата |
| `--debug` | сохранить промежуточные картинки (что нашлось, маска, очищенный фон) |

### Логотип в углу

Логотип лежит в `assets/logo.png` и ставится в левый верхний угол каждого постера.
Заменить — положи свой PNG с прозрачным фоном туда же. Другой угол — `--logo-corner tr|bl|br`,
без логотипа — `--logo none`.

## Telegram-бот

1. Создай бота у [@BotFather](https://t.me/BotFather) и положи токен в файл `bot_token.txt`.
2. Один раз запусти `run.bat` (поставит библиотеки), потом `bot.bat` (или `./bot.sh`).
3. Пиши боту:
   - `13759` или ссылку — получишь постер (картинкой и файлом без сжатия);
   - `13759 | НОВАЯ ОЗВУЧКА` — с плашкой;
   - картинку с подписью `13759` — сделает постер из твоей картинки.

Переменные окружения: `BADGE` — плашка по умолчанию, `ALLOWED_USERS` — ID тех, кому можно
пользоваться ботом (через запятую).

## Как это работает

1. `postergen/shikimori.py` — данные и постер (GraphQL, запасной REST, домены
   shikimori.io → shikimori.one → shiki.one → shikimori.me; свой домен — переменная `SHIKIMORI_URL`).
2. `postergen/detect.py` — поиск текста (RapidOCR, модели уже внутри пакета) и выбор блока
   с японским названием.
3. `postergen/logo.py` — разбор логотипа: точная маска букв с обводкой (персонажи вокруг
   не задеваются), цвета букв по порядку, табличка/лепесток, толщина обводки.
4. `postergen/inpaint.py` — стирание. При первом запуске скачивается нейросеть **LaMa**
   (~90 МБ, из зоопарка моделей OpenCV на GitHub; запасной источник — HuggingFace). Она
   дорисовывает фон под стёртым текстом без размытия. Первый постер делается ~30 с, дальше
   быстрее. Если скачать не вышло, используется встроенный способ OpenCV (по краям может быть
   размытие). Модель можно положить вручную в `models/`:
   `https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/inpainting_lama/inpainting_lama_2025jan.onnx`
5. `postergen/compose.py`, `elements.py`, `typo.py` — раскладка и отрисовка русского текста.

## Ограничения

- Точный шрифт оригинала угадать нельзя: подбирается похожий из набора —
  Dela Gothic One (жирный), Rubik Dirt (потёртый), M PLUS Rounded (округлый), Russo One («техно»),
  Playfair Display (с засечками). Свой выбор: `--font heavy|grunge|rounded|tech|serif`
  или `--font путь/к/шрифту.ttf`.
- Очень сложные логотипы (буквы на фоне со сложной текстурой, 3D) распознаются хуже —
  тогда помогает `--title`, `--mode overlay` или `--debug`, чтобы посмотреть, что нашлось.
